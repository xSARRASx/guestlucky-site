Lucky Copilot — page de demo

Cette page sert a tester localement le widget de chat avant de l'integrer dans guestlucky.com.

Comment l'utiliser

  1. Verifier qu'un fichier .env existe a cote de chat.php avec GEMINI_API_KEY=....
  2. Lancer un serveur PHP local : php -S localhost:8000 dans ce dossier.
  3. Ouvrir http://localhost:8000/index.html.
  4. Cliquer sur la bulle violette en bas a droite.
  5. Poser une question.
Une fois que tu as valide que ca marche, copie-colle le snippet de widget-embed.html dans chaque page de guestlucky.com ou tu veux que le widget apparaisse.
